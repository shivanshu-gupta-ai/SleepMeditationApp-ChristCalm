# Frontend architecture (reference: Expo)

Product UX contracts: [03-user-flows-and-screens.md](./03-user-flows-and-screens.md), [05-design-system.md](./05-design-system.md).  
This doc is **how the reference client is structured**.

---

## App bootstrap

```
expo-router entry
  → app/_layout.tsx
      · load fonts (Inter)
      · ThemeProvider (Nest/Cooper)
      · AuthProvider (Cognito session)
      · RevenueCatProvider (if keys present)
      · ViewportProvider
      · startAnalytics()
  → app/index.tsx
      · if no session → auth or onboarding
      · if onboarding incomplete → onboarding
      · else → /(tabs)/home
```

---

## Navigation model

```
Root Stack
├── index (gate)
├── onboarding
├── (auth) group
│   ├── sign-in | sign-up | confirm-email
│   ├── forgot-password | reset-password
├── (tabs) group
│   ├── home | meditate | wisdom | journal | prayers | profile
│   └── FloatingTabBar + StartCalm FAB
├── meditation/[id]     # immersive, hide tabs
├── sos
├── paywall
├── ai-prayer
└── oauth
```

Tab bar: custom `FloatingTabBar` (not default RN tabs chrome).  
FAB opens `StartCalmSheet` (emotion / SOS / Wisdom).

## State management

| Concern | Mechanism |
|---------|-----------|
| Auth user + token | `AuthContext` + SecureStore |
| Theme | `ThemeContext` + persisted preference |
| Premium | `usePremium` / RevenueCat + `/auth/me` flags |
| Onboarding draft | AsyncStorage `cc_onboarding_draft` |
| Catalog | Fetch + `api-cache` memory TTL |
| Wisdom thread | Local screen state + server history |
| Analytics buffer | Local then flush |
| Soft paywall flag | utils/storage |

No global Redux required; Context + hooks are enough for MVP.

## API client

`frontend/src/api/client.ts`:

- Base: `process.env.EXPO_PUBLIC_BACKEND_URL` + `/api`
- Attaches Bearer from auth session
- Methods mirror [08-api-contract.md](./08-api-contract.md)
- Surfaces HTTP errors without crashing UI (ErrorState)

### Public env vars

| Variable | Purpose |
|----------|---------|
| `EXPO_PUBLIC_BACKEND_URL` | API Gateway base |
| `EXPO_PUBLIC_COGNITO_USER_POOL_ID` | Auth |
| `EXPO_PUBLIC_COGNITO_CLIENT_ID` | Auth |
| `EXPO_PUBLIC_COGNITO_DOMAIN` | Hosted UI |
| `EXPO_PUBLIC_COGNITO_REGION` | Region |
| `EXPO_PUBLIC_REVENUECAT_*` | Public SDK keys / product ids |
| `EXPO_PUBLIC_UNLOCK_ALL` | Preview unlock (non-prod) |

Generated by `./scripts/sync-env-from-aws.sh` — disposable, no secrets.

## Feature modules

### Auth (`src/features/auth/`)

- `cognito.ts` — signUp, signIn, forgot password, OAuth/Apple  
- `AuthContext` — session hydrate, signOut, refresh user  
- Buttons: Apple, divider, etc.  
- Token in **SecureStore** (native); web equivalent storage  

### Onboarding (`src/features/onboarding/`)

- `constants.ts` — all question copy and option ids  
- Components: GraceCompanion, OnboardingOption, Progress, StepLayout  
- Screen: `app/onboarding.tsx` drives step machine  
- Draft util persists progress  

### Subscriptions (`src/features/subscriptions/`)

- RevenueCat configure with public keys  
- `ENTITLEMENT_ID = christcalm_premium`  
- Products: monthly / annual  
- After purchase → `POST /subscription/sync`  
- `usePremium()` gates UI

## Media playback

- `expo-audio` (or AV) for streaming `audio_url`  
- Covers: bundled map in `meditation-covers.ts` + remote URL fallback  
- Player screen: pulse artwork, scrubber, complete → API + soft paywall util

## Theming

```
tokens.ts → lightColors | darkColors
layout.ts → spacing, radius, fab size
ThemeContext → colors, scheme, toggle
useTheme() in every screen — never hardcode hex
```

Default: **dark (Nest)**.

---

## Analytics client

`utils/analytics.ts`:

- `track(name, props?)` — scalar props only  
- Buffer + flush to `POST /analytics/events`  
- `startAnalytics` from root layout  
- Never attach journal body

## Platform split

| Concern | Native | Web |
|---------|--------|-----|

| IAP | RevenueCat stores | limited / skip |

`utils/storage/index.ts` vs `index.web.ts` pattern.

## Performance tactics

1. Catalog client cache (5 min)  
2. Bundle cover images for LCP of lists  
3. Lazy-heavy screens via router  
4. Avoid re-render storms in Wisdom list (stable keys)  
5. Prefetch meditations when emotion selected (optional)
