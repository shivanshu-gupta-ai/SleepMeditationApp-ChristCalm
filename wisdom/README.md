# Wisdom corpus (RAG)

Markdown files here are loaded by the ChristCalm backend for **conversational wisdom** (“What would Jesus say?”).

| File | Role |
|------|------|
| `Wisdom_Handbook.md` | Practical wisdom by topic (mind, emotions, relationships, etc.) |
| `jesus_voice.md` | Tone + gospel-shaped pastoral framing |

The Lambda package includes this folder. Retrieval is keyword/topic based over section chunks — keep headings (`##`) clear for best RAG.

Do not put secrets in this folder.
